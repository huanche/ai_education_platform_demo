Demo 课程、用户、完整演示流程、明确不做的功能

	
| 资源/操作 | 教师 | 学生 |
|---|---|---|
| 创建课程 | 可以 | 不可以 |
| 编辑自己的课程 | 可以 | 不可以 |
| 创建、编辑活动草稿 | 可以 | 不可以 |
| 发布活动 | 可以 | 不可以 |
| 加入课程 | 不需要 | 可以 |
| 查看已发布活动 | 自己的课程 | 已加入的课程 |
| 提交答案 | 不可以 | 自己已加入课程的活动 |
| 查看作答 | 自己课程内学生的作答 | 只能看自己的作答 |
| 调用教师 Agent | 可以 | 不可以 |
| 调用学生 Agent | 不可以 | 可以，但限于当前学习活动 |
